# MiniDroid — Android APK

Kivy-приложение виртуального дроида: заряд, масло, опыт, очистка пыли, реакции, мини-игра, TTS и акселерометр при поддержке устройства.

## Получение APK
1. Откройте вкладку **Actions** в репозитории.
2. Выберите **Build MiniDroid APK** и нажмите **Run workflow**.
3. Дождитесь завершения сборки.
4. В артефактах запуска скачайте **MiniDroid-debug-apk** и распакуйте APK.

Сборка создаёт debug APK, не production-релиз. Сборка и запуск на реальном Android-устройстве должны быть подтверждены успешным завершением workflow и отдельным тестированием.
